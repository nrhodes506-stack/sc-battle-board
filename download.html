How to use it

01
Download the parser

Click the download button above and save sc_log_parser.exe somewhere on your PC — your Desktop is fine.

02
Run it before you play

Double-click sc_log_parser.exe. No window will appear — instead look for a small crosshair icon in your system tray, near the clock in the bottom right of your screen. It may be hidden under the ^ arrow.

03
Launch Star Citizen and play normally

The parser watches your game log in the background. You don't need to do anything else — just play.

04
Check the kill feed

Visit sc-battle-board.vercel.app and your kills will appear automatically. Search your player name to see your full stats.

The tray icon

Right-click the crosshair icon in your system tray to see a menu:

Click Exit to stop the parser completely. It will not restart automatically unless you run the exe again.

Windows security warning

⚠ Windows may flag this file

When you first run the parser, Windows Defender or SmartScreen may show a warning saying the file is from an "unknown publisher." This is normal for community tools that haven't been through Microsoft's signing process. The parser is safe — it only reads your game log file and sends kill data to SC-Battle-Board.

If you see a blue SmartScreen popup:

1
Click "More info"

This reveals the option to run the file anyway.

2
Click "Run anyway"

The parser will start and the tray icon will appear.

Common questions

Does it affect my game performance?
No. The parser uses around 25mb of RAM and almost zero CPU — it's just reading a text file in the background. You won't notice it running.
What data does it collect?
Only kill events from your game log — who killed whom, with what weapon, in which zone, and when. It reads nothing else from your PC and sends nothing else to the server.
My kills aren't appearing on the site
Check the tray icon is showing "Watching for kills" rather than an error. If Star Citizen was already running when you started the parser, it will only capture kills from that point forward — not ones that happened before you launched it.
How do I stop it running?
Right-click the crosshair icon in the system tray and click Exit. The parser will stop immediately.
Does it start automatically when I turn my PC on?
No — you need to run the exe manually each time. Just double-click it before you launch Star Citizen.
Something isn't working
Join the SC-Battle-Board Discord and post in #parser-support. Include a screenshot of the tray icon menu showing the current status.
